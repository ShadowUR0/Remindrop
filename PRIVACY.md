# Privacy Policy

Remindrop is designed to work without collecting or transmitting personal data.

## Data collection

Remindrop does not collect analytics, advertising identifiers, crash reports, telemetry, account information, or usage statistics.

## Network access

Remindrop does not request the Android `INTERNET` permission. The app itself cannot upload reminders, shared text, links, identifiers, or usage data to a server.

Opening a saved link hands that link to another installed app or web browser. Any network activity after that point belongs to the app that opens the link, not Remindrop.

## Local data

Reminder titles, shared text, links, source hints, dates, and completion state are stored only in Remindrop's private app storage on the device.

Android cloud backup is disabled for Remindrop.

## Permissions

Remindrop may request:

- Notification permission on Android 13 and newer, solely to display reminders
- Boot-completed delivery, solely to reschedule pending reminders after a reboot

Remindrop does not request access to photos, files, location, contacts, camera, microphone, or advertising identifiers.

## Third-party services

Remindrop contains no advertising SDKs, analytics SDKs, push-notification providers, or hosted backend integrations.

## Deleting data

Individual reminders can be deleted in the app. Uninstalling Remindrop removes its local app data according to Android's normal behavior.

## Changes

Material privacy changes will be documented in the repository alongside the source code.
